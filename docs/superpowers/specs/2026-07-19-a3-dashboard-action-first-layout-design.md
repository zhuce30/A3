# A3 首页“学习动作优先”布局修复设计

## 1. 背景

生产环境 `/a3/dashboard` 在真实任务标题较长时出现以下问题：

- Dashboard 网格使用普通 `1fr`，子卡片根节点缺少 `min-width: 0`，长文本触发 CSS Grid 的最小内容宽度扩张。
- “学生资料”“AI 助学助手”等卡片被压成极窄列，中文逐字换行。
- 后续卡片被推到可视区右侧，产生横向溢出，用户误以为内容缺失。
- 多个卡片使用统一最小高度，内容较少时留下大面积空白。
- 首页信息虽然完整，但“今天先做什么”的学习主线不够突出。

本次采用用户确认的 B 方案：学习动作优先。

## 2. 目标

1. 首页首屏优先回答“今天该学什么、还需多久、完成后去哪”。
2. 保留现有学习路径、画像、诊断、报告、推荐、AI 辅导和测评模块。
3. 修复长标题导致的横向溢出、卡片挤压和中文逐字竖排。
4. 桌面、平板和移动端均保持清楚的阅读顺序。
5. 不修改任何后端接口、请求字段、响应字段或数据回流逻辑。

## 3. 页面结构

### 3.1 页面标题区

保留当前问候语、路径进度和“AI 辅导可用”状态。标题区只调整必要的响应式换行，不改变数据来源或交互入口。

### 3.2 首屏行动区

桌面端使用约 `2:1` 的两列结构：

- 主列：今日任务、周目标进度、今日剩余时长、“现在最该做”及主要 CTA。
- 辅列：连续学习、学习徽章和通知提醒，以紧凑信息块纵向排列。

今日任务直接使用现有 `tasks`、`motivation` 和 `planRelationship` 数据，不新增前端假数据。任务标题允许显示两行，副标题允许显示两行。

### 3.3 路径与个人概况区

桌面端继续使用约 `2:1` 两列结构：

- 主列：当前学习路径、进度、当前节点和下一步动作。
- 辅列：头像、专业方向、学习天数、答题数和正确率。

个人概况不再作为可能被压缩的三列网格首项，确保至少具备可读宽度。

### 3.4 学情与支持区

以下模块全部保留：

- 动态画像信号
- 学情诊断
- 学习数据概览
- 薄弱知识点提醒
- 推荐资源
- AI 助学助手
- 即将到来的活动
- 最近测评表现

这些模块按信息关联重新分组，但不改变组件内部数据契约。桌面端使用显式 `minmax(0, ...)` 网格；平板端降为双列；移动端为单列。

## 4. 布局与文本规则

- Dashboard 网格轨道必须使用 `minmax(0, ...)`，禁止直接依赖可能被内容撑开的普通 `1fr`。
- 所有网格直接子项必须具备 `min-w-0`。
- 通用 `A3Card` 根节点补充 `min-w-0`，防止其他 A3 网格重复出现同类问题。
- 任务标题使用两行截断和 `break-words`，不能使用单行 `truncate` 隐藏关键信息。
- 任务副标题使用两行截断；异常长的连续英文或符号也必须换行。
- CTA、状态图标和计数器必须 `shrink-0`，不能挤压主要文本。
- 卡片高度以内容自然撑开为主，仅对需要对齐的同组卡片使用一致高度。
- 页面不能产生横向滚动条。

## 5. 响应式顺序

### 宽屏桌面

1. 标题区
2. 今日行动主区 + 连续学习/提醒辅区
3. 学习路径 + 个人学习概况
4. 动态画像与学情诊断
5. 数据、薄弱点、资源、AI 辅导、活动和测评

### 平板与窄桌面

- 主区降为双列或上下布局。
- 所有卡片最小宽度归零，长文本正常换行。
- 不保留会造成内容过窄的三列比例。

### 移动端

按以下顺序单列展示：

1. 今日任务
2. 当前学习路径
3. 连续学习和提醒
4. 个人学习概况
5. 动态画像与其他学习支持模块

## 6. 数据与接口边界

继续使用现有接口：

- `GET /api/learning/dashboard/`
- `GET /api/assessments/report/`
- `GET /api/learning/classroom/`
- `GET /api/learning/study-plan/?auto=1`
- `GET /api/profiles/me/`

本次不修改 Django、Next API 代理、Agent、数据库模型和响应类型。所有按钮继续指向现有真实路由。

## 7. 状态处理

- 加载状态继续显示现有任务加载指示。
- 无任务时保留由 `buildTasks` 生成的真实下一步入口，不增加 mock 任务。
- 接口部分失败时，其他成功数据仍可展示。
- 空画像、空资源、空薄弱点继续使用现有空状态文案。

## 8. 验收标准

1. 真实长任务标题不会扩大页面宽度。
2. 1920、1440、1024 和 390 像素视口均无横向溢出。
3. 学生资料和 AI 助手不再出现中文逐字竖排。
4. 今日任务位于首页第一主视觉区，用户无需向下寻找当前行动。
5. 所有原有数据模块和真实链接仍存在。
6. TypeScript、lint 和 Dashboard 相关测试通过。
7. Playwright 截图验证桌面与移动端布局，无重叠、截断失控或大面积异常空白。

## 9. 非目标

- 不重做首页视觉品牌。
- 不修改侧边栏、顶部栏或全站导航。
- 不新增后端接口或数据库字段。
- 不改变学习任务、推荐、画像和报告的业务算法。
- 不删除现有首页功能模块。
