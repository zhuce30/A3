# A3 侧栏页面入口与栏目分组设计

## 目标

解决侧栏父级项目同时表现为栏目标题和页面链接造成的歧义，让用户明确区分“展开栏目”和“进入页面”。

## 信息架构

- 有子页面的父级只作为可折叠栏目按钮，不再直接跳转。
- 原父级路由保留，并作为栏目中的第一个真实页面入口：
  - 今日学习 -> 今日任务
  - 学习规划 -> 计划总览
  - 练习复盘 -> 练习中心
  - AI 学习 -> AI 课堂
  - 知识库 -> 知识库首页
- 学习报告、教师工作台等无子页面项目继续作为独立页面入口。
- 不修改任何现有 URL、鉴权规则或业务接口。

## 交互与视觉

- 栏目按钮使用图标、栏目名称和右侧展开箭头，点击仅切换展开状态。
- 当前路由所属栏目自动展开；其他栏目可由用户独立展开或收起。
- 栏目激活只使用低对比背景和强调文字，不使用页面选中态。
- 真实页面子项统一缩进；当前页面使用现有品牌强调色选中态。
- 按钮提供 `aria-expanded`、`aria-controls`，子项容器提供稳定 id，支持键盘操作。
- 展开动画只改变透明度和变换，不使用复杂装饰动效。

## 国际化

新增五个中英文页面入口文案，栏目名称继续沿用现有导航文案。所有真实页面入口均通过 i18n 显示。

## 验收

- 父级栏目渲染为 `button`，不包含导航链接。
- 每个栏目包含原父级路由对应的第一个子入口。
- 当前子页面和原父级页面均能正确高亮，并自动展开所属栏目。
- 学习报告仍是独立链接并能显示当前页面状态。
- 桌面侧栏不溢出，英文文案不截断，键盘和屏幕阅读器可识别展开状态。
