# 智学引擎 A3 产品首页设计方案

日期：2026-07-11

状态：已确认

## 1. 项目背景

当前 `/a3` 会直接跳转到 `/a3/dashboard`。本次设计将 `/a3` 改为智学引擎的产品展示首页，并保留现有学习工作区与业务路由。

首页面向两类用户：大学生和比赛评委。大学生是第一叙事对象，首页需要让学生理解产品如何帮助自己学习，并引导其注册。评委是第二叙事对象，首页需要用真实产品界面、真实课程资料和真实数据回流证明系统已经形成可运行的学习闭环。

首页不是功能清单、答辩材料或静态概念页。它以一个操作系统学习案例贯穿整页，让访客看到一次完整的个性化学习经历。

## 2. 产品定位

品牌名称统一使用“智学引擎”。

首屏主标题：

```text
每一步学习，
都更懂你。
```

首屏辅助表达：

```text
一群懂学习的智能体，陪你找到自己的节奏。
```

主转化目标是注册体验。主按钮使用“开启我的智学旅程”，进入 `/a3/register`。

首页对多智能体、多模态和本地知识库的介绍保持克制。技术术语不在首屏集中出现，而是在后续章节中通过真实界面和短标签自然呈现。

## 3. 核心叙事

整页使用一名虚构演示学生的操作系统学习经历：

```text
建立学习画像
-> 完成入学诊断
-> 发现“进程调度”薄弱
-> 从本地知识库检索操作系统课本、课程 PPT 和知识总结
-> 生成个性化 AI 课堂
-> 进入实时辅导
-> 将练习与反馈写回学习计划
```

本地知识库不是与其他能力并列的功能卡片，而是画像、诊断、课堂、辅导、引用验证和学习反馈共同依赖的内容底座。

## 4. 页面结构

### 4.1 顶部导航

导航左侧显示“智学引擎”。

页内定位项：

```text
产品能力
学习闭环
真实证据
联系我们
```

真实路由项：

```text
登录
评审体验
开启旅程
```

移动端折叠次要导航，但“开启旅程”始终可见。

### 4.2 首屏

首屏使用深色背景和裁切、叠放的真实产品界面。画像、诊断、知识库和课堂界面缓慢切换，鼠标悬停时暂停。

首屏只保留主标题、辅助表达和主按钮。首屏不展示团队名称、比赛名称或 OpenMAIC 标识。

### 4.3 学习画像

章节标题：

```text
先认识你。
```

展示目标、基础水平、每日学习时间和资源偏好如何组成画像。此处使用完整、可读的产品界面，不再使用首屏式裁切。

### 4.4 入学诊断

章节标题：

```text
找到你的起点。
```

以“进程调度”诊断题为案例，展示系统如何判断当前水平、识别薄弱点并决定下一步。页面不把分数作为唯一结果。

### 4.5 本地知识库

章节标题：

```text
让资料真正为你所用。
```

该章节是整页的视觉中心。操作系统课本、课程 PPT 和知识总结进入知识库，形成可检索、可引用的学习依据。资料只展示课程名称、章节和资料类型，不展示本地路径、文件哈希或上传目录。

### 4.6 AI 课堂

章节标题：

```text
走进为你生成的课堂。
```

展示系统如何结合画像、诊断结果和知识库资料生成课堂。首页允许切换“讲解”和“引用”两个只读视图，但不在首页直接调用资源生成接口。

### 4.7 实时辅导

章节标题：

```text
随时有人陪你学懂。
```

使用现有数字教师形象。章节进入视口后静音播放 6 至 10 秒短演示，包括教师出现、进入倾听状态和学习问题浮现。用户主动点击后才允许播放声音或进入正式辅导流程。

### 4.8 真实证据

章节标题：

```text
每一步，
都有据可循。
```

辅助表达：

```text
从资料来源到学习进展，过程清清楚楚。
```

该章节只突出三项证据：

```text
资料可检索
来源可验证
结果会写回
```

页面可以展示真实检索指标、引用验证状态和闭环验证结果，但不得展示未经真实测量的提分率、准确率或用户量。

### 4.9 教师工作台

章节标题：

```text
及时看见，也能及时介入。
```

该章节在真实证据之后以较小横向区块呈现，证明教师能够查看学生进度、薄弱点和风险，并推送干预任务。教师工作台不抢占学生主叙事。

### 4.10 收尾与页尾

收尾标题：

```text
开启你的智学旅程。
```

主按钮进入 `/a3/register`。联系邮箱作为次要信息，不设置预约合作表单。

页尾展示：

```text
团队：这次不要意味何
比赛：A3-基于大模型的个性化资源生成与学习多智能体系统开发
邮箱：3062221819@qq.com
```

比赛名称不出现在首屏或导航中。

## 5. 视觉系统

整体方向为“深色展厅 + 明亮产品界面”。背景接近黑色，真实产品截图保留原有浅色界面，使产品本身成为页面中的视觉焦点。

强调色使用克制的荧光黄绿。首页不使用大面积蓝紫 AI 渐变、粒子背景、鼠标光效、装饰性光球或纯氛围插画。

中文标题使用粗黑体和短句。正文通常不超过两行。英文仅用作小型章节编号，例如 `03 / KNOWLEDGE`，不承担核心信息表达。字号不随视口宽度连续缩放，使用明确的响应式断点。

首页不堆叠悬浮卡片。产品界面在首屏允许裁切和叠放，在后续功能章节中完整展示。

## 6. 动效与媒体

桌面端使用连续滚动叙事。章节依次展示“认识你、找到起点、理解资料、进入课堂、实时辅导”。每个滚动阶段只出现一个短句和一个主要产品状态。

不使用强制横向滚动。页面开场动画控制在约 0.8 秒，不设置进度条、长时间遮罩或“点击进入”。

知识库章节通过资料节点汇入知识库，再连接课堂、引用和学习计划，形成整页视觉高潮。

移动端取消复杂固定滚动，改为轻量淡入和界面切换。页面必须尊重系统的“减少动态效果”设置。

全站默认静音。产品视频或数字教师演示只有在用户主动操作后才能播放声音。视频加载失败时退回静态产品画面。

## 7. 路由与交互

```text
开启我的智学旅程 -> /a3/register
开启旅程 -> /a3/register
登录 -> /a3/login
评审体验 -> /a3/login?mode=review
```

评审模式的登录页展示预置评审账号，并提供一键填入。评委仍需主动点击登录，不提供免登录旁路。

未登录用户点击课堂、辅导等深层入口时进入登录流程，登录成功后返回原目标页面。

首页中的产品能力、学习闭环、真实证据和联系我们均为页内平滑定位。联系邮箱使用 `mailto:3062221819@qq.com`。

首页不触发资源生成，不写入演示数据，也不在前端构造虚假任务、指标或 artifact。

## 8. 内容与隐私边界

- 只使用真实产品页面、真实课程资料和真实验证结果。
- 演示学生使用固定虚构身份，页面不展示真实个人数据。
- 不展示 API key、签名链接、本地绝对路径、文件哈希或上传目录。
- 不展示 OpenMAIC 名称或标识。
- 不展示未经测量的提分率、准确率、用户量或商业规模。
- 团队名称仅在页尾出现。
- 首页第一版只提供中文，英文仅作为少量视觉标签。

## 9. 状态与降级

- 产品截图加载前使用固定尺寸占位，避免布局跳动。
- 媒体加载失败时显示对应静态产品界面。
- 动效不可用或用户开启“减少动态效果”时，所有内容仍可顺序阅读。
- 移动端导航折叠后，注册入口仍然可见。
- 页面不依赖自动播放音频才能理解内容。
- 真实指标不可用时隐藏指标，不用假数据补位。

## 10. 实现边界

本次首页建设应复用现有 Next.js、A3 组件、路由和设计资源。实现可以新增首页专用组件与经过处理的媒体资源，但不得破坏现有业务页面或接口契约。

`/a3` 从重定向页变为产品展示首页。已登录用户仍可通过首页导航进入现有学习工作区。首页不替代 `/a3/dashboard`、`/a3/today` 或 `/a3/demo-flow` 的业务职责。

## 11. 验收标准

功能验收：

- `/a3` 展示产品首页，不再自动跳转仪表盘。
- 注册、登录、评审体验和页内导航指向正确目标。
- 评审模式展示预置账号并支持一键填入。
- 登录后可返回用户原本选择的深层功能。
- 邮箱链接可用。

内容验收：

- 首屏不出现团队名、比赛名或 OpenMAIC 标识。
- 操作系统案例贯穿画像、诊断、知识库、课堂、辅导和结果写回。
- 三项证据均来自真实系统状态。
- 页面无本地路径、哈希、密钥、签名链接或真实学生隐私。

视觉验收：

- 桌面端和移动端无文字溢出、界面遮挡或不连贯重叠。
- 首屏截图裁切有明确焦点，后续章节界面完整可读。
- 移动端不运行复杂固定滚动。
- 减少动态效果模式下内容完整。
- 视频失败时有静态回退。

工程验收：

```powershell
cd OpenMAIC
npx.cmd tsc --noEmit
pnpm.cmd lint
```

新增首页相关单元测试，并用 Playwright 验证桌面端与移动端的主 CTA、评审入口、导航定位、文字布局和媒体回退。使用截图检查首屏构图与关键章节。首页媒体不得阻塞主要文字和 CTA 的首次呈现。
