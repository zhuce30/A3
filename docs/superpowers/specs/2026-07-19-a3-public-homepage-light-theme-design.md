# A3 公开首页浅色主题与真实素材升级设计

## 1. 背景

当前 `/a3` 公开首页采用接近纯黑的页面背景和荧光黄绿色操作色。该方案具有较强视觉冲击，但与登录后的浅色学习产品差异过大，也容易让真实系统截图显得像嵌入的另一套产品。

本次升级把公开首页调整为柔和、可信、适合教育产品长期使用的浅色体系，并使用近期真实系统截图替换陈旧素材。公开首页仍负责产品介绍、登录和注册，不承载用户手册正文。

## 2. 目标

- 将公开首页从深色主题调整为奶油黄、白色、深墨绿组成的浅色主题。
- 保留“智学引擎，把每一次学习，接到下一步”的核心产品表达。
- 使用真实学习页面解释学习闭环，而不是使用抽象装饰图或伪造界面。
- 让公开首页与登录后的 A3 学习区在视觉上属于同一个产品。
- 保持现有 `/a3` 路由、登录注册入口、锚点导航和产品能力声明不变。
- 不修改 Django、Agent 或 OpenMAIC 业务接口。

## 3. 非目标

- 不重构登录后的 `/a3/dashboard`。
- 不把 `/a3/help` 的文章内容直接放进公开首页。
- 不给系统截图强制套色或修改截图中的真实业务状态。
- 不增加无法通过真实页面或接口证明的新产品能力声明。
- 不引入渐变、装饰光球、纯氛围图片或与学习产品无关的素材。

## 4. 信息架构

公开首页继续使用现有信息架构：

1. 顶部导航：品牌、学习闭环、真实产品、可信依据、教师端、登录、进入学习区、开始体验。
2. 首屏：产品名称、核心主张、支持文案、主次行动、可信特征和真实界面组合。
3. 学习闭环：今日任务、画像与诊断、知识库、资源推荐、AI 课堂、面对面辅导、测评与错题、报告与计划刷新。
4. 教师端：教师工作台和干预链路。
5. 可信依据：可验证能力、隐私与安全、常见问题。
6. 收尾行动和页脚：注册、登录、隐私说明、帮助与手册。

`/a3/help` 仅通过顶部问号、页脚“帮助与手册”等入口访问，不与首页正文合并。

## 5. 视觉系统

### 5.1 核心颜色

| 用途 | 颜色 | 说明 |
|---|---|---|
| 首屏与重点内容带 | `#FFF8D8` | 柔和奶油黄，不覆盖全部页面 |
| 主操作、链接、关键编号 | `#245C48` | 深墨绿，替代首页蓝色按钮 |
| 主标题和正文墨色 | `#18231F` | 提供稳定、清晰的阅读对比 |
| 普通内容区 | `#FFFFFF` | 保持页面呼吸感 |
| 次级浅底 | `#F3F7F4` | 用于可信依据、流程说明等辅助区域 |
| 警示和证据提示 | `#9A6A00` | 低面积使用，不作为主按钮颜色 |

颜色使用规则：

- 深墨绿仅用于主按钮、文本链接、焦点轮廓、步骤编号和少量强调。
- 奶油黄用于首屏、重点内容带和提示区域，不把整页处理成单一黄色。
- 白色和浅灰绿色交替承载长内容，避免一页只有一种色相。
- 真实系统截图保留原始颜色，截图中的蓝色不等同于公开首页品牌主色。
- 页面不使用渐变背景。

### 5.2 形态与层级

- 卡片圆角不超过现有设计系统的 8px。
- 页面章节使用全宽色带和受约束内容区，不把每个章节做成悬浮卡片。
- 产品截图使用轻边框和低强度阴影，保证真实界面仍可读。
- 标题尺寸匹配内容层级，首屏标题最大，普通章节标题不使用首屏字号。
- 主按钮使用深墨绿实底；次按钮使用深墨绿描边或文本链接。

## 6. 真实素材映射

素材从仓库内的页面截图材料中选择，实施时复制到前端公开资源目录并改为稳定的 ASCII 文件名。原始中文文件名和本地绝对路径不进入页面代码。

| 首页区域 | 推荐真实截图 |
|---|---|
| 首屏界面组合 | 今日任务、学习报告 |
| 画像与诊断 | 画像构建、入学诊断 |
| 今日学习 | 今日任务、计划总览 |
| 知识库依据 | 系统资料、知识图谱 |
| 个性化资源 | 资源推荐、生成的讲解文档、PPT、思维导图、专项练习和视频 |
| AI 课堂 | AI 课堂界面 |
| 面对面辅导 | 面对面界面 |
| 测评与复习 | 练习中心、错题本 |
| 报告回流 | 学习报告 |
| 教师端 | 教师工作台 |

实施时每张图片必须：

- 有准确的中文 `alt` 文本。
- 使用 Next.js `Image` 或现有产品媒体组件。
- 提供桌面端和移动端合适的 `sizes`。
- 不展示 API key、签名地址、本地路径或真实隐私数据。
- 优先裁掉浏览器系统水印和与产品无关的画面边缘，但不裁掉关键业务状态。

## 7. 首屏布局

桌面端使用左侧文案、右侧真实系统截图组合：

- 左侧先显示产品名“智学引擎”，再显示“把每一次学习，接到下一步”。
- 主按钮为深墨绿“开始体验”。
- 次按钮为深墨绿描边“查看完整学习闭环”。
- 右侧以前景截图和低透明度后景截图表达任务到报告的连续关系。
- 首屏底部在常见桌面高度下露出下一章节标题或截图边缘，提示用户继续滚动。

移动端改为单列：

- 文案和行动在前，真实截图在后。
- 截图组合采用稳定纵横比，不让动态内容改变首屏高度。
- 不按视口宽度缩放字体字号。
- 360px 宽度下按钮允许换行，但文字不得溢出或互相遮挡。

## 8. 组件与代码边界

沿用当前组件边界：

- `a3-product-homepage.tsx`：公开首页骨架和导航。
- `a3-homepage-hero.tsx`：首屏文案与产品截图组合。
- `a3-homepage-story.tsx`：学习闭环、可信依据、教师端和页脚。
- `a3-homepage-content.ts`：文案、路由和媒体清单。
- `a3-product-homepage.module.css`：浅色主题、响应式布局和动效降级。

可以在 CSS 模块顶层增加页面级颜色变量，避免在多个选择器中重复硬编码。此次不借机重构与首页无关的 A3 组件。

## 9. 状态与可访问性

- 所有导航和行动保持键盘可访问。
- 焦点轮廓使用深墨绿，并在奶油黄和白色背景上满足可见性要求。
- 图片加载失败时保留稳定尺寸和可读替代文本，不让布局坍塌。
- `prefers-reduced-motion` 下停止截图轮播或层叠动画。
- 公开首页在后端不可用时仍应能加载；登录、注册和进入学习区链接保持明确。

## 10. 验证标准

### 自动验证

- `npx.cmd tsc --noEmit`
- `pnpm.cmd lint`
- 现有首页内容、公开路由、韧性和 hero 质量测试。
- 更新受颜色、媒体和文案变化影响的首页测试断言。

### 视觉验证

- Playwright 截图覆盖 1440x900、1280x720、390x844、360x800。
- 首屏可见品牌、核心主张、主行动和真实产品界面。
- 常见桌面与移动视口都能看到下一章节提示。
- 页面不存在纯黑内容带、蓝色首页主按钮、文本溢出或截图遮挡。
- 深墨绿按钮与奶油黄背景达到可读对比度。

## 11. 验收结果

完成后，用户进入 `/a3` 时看到的是与学习区一致的浅色教育产品首页。奶油黄建立亲和感，深墨绿承担操作和品牌识别，真实系统截图清楚展示学习闭环；帮助内容通过独立 `/a3/help` 访问，不与公开首页混合。
