# A3 帮助中心与选择性新手导览设计

## 1. 背景

A3 已存在 `/a3/help`、顶部问号入口、搜索和六篇基础帮助内容，但当前形态更接近帮助卡片集合，无法覆盖完整学习闭环，也缺少带真实截图的文章详情和复杂流程首次引导。

本次升级采用双层帮助模型：

1. 独立帮助中心解决“我忘了怎么做，需要查找答案”。
2. 页面内新手导览解决“我第一次进入复杂页面，不知道从哪里开始”。

两者保持独立。新手导览不能替代可搜索、可反复查阅的用户手册。

## 2. 目标

- 升级现有 `/a3/help`，而不是创建另一套重复帮助页面。
- 支持按关键词、用户任务和功能分类查找答案。
- 增加 `/a3/help/[articleId]` 文章详情页。
- 使用真实系统截图、编号标注和可执行步骤讲解功能。
- 所有“前往操作”按钮指向已有真实 A3 路由。
- 首批为五个高学习成本流程提供 3 至 5 步新手导览。
- 不修改 Django、Agent 或 OpenMAIC 接口。

## 3. 非目标

- 不把 `/a3/demo-flow` 或 `/a3/capabilities` 改造成用户手册。
- 不在公开首页正文中嵌入完整帮助文章。
- 不为每个页面都自动弹出新手导览。
- 不增加没有真实目标页面的帮助按钮。
- 不使用前端 mock 冒充后端任务成功、资源已生成或知识库已完成解析。
- 第一阶段不开发帮助反馈统计后端，避免出现无数据去向的“是否有帮助”按钮。

## 4. 路由与入口

| 路由或入口 | 职责 |
|---|---|
| `/a3/help` | 搜索、分类、快速开始和常用操作 |
| `/a3/help/[articleId]` | 单篇完整操作文章 |
| 顶部问号 | 搜索简要答案、打开本页帮助或进入帮助中心 |
| 登录后侧边栏底部“帮助与手册” | 稳定进入 `/a3/help` |
| 公开首页页脚“帮助与手册” | 从 `/a3` 进入独立帮助中心 |
| 文章内“前往操作” | 进入已有真实业务页面 |
| 文章内“重新播放导览” | 在支持的业务页面启动对应导览 |

帮助中心与公开首页只共享品牌视觉和截图素材，不共享页面正文结构。

## 5. 帮助中心信息架构

### 5.1 分类

1. 快速开始
2. 账号、隐私与学习画像
3. 今日任务与学习计划
4. AI 课堂与面对面辅导
5. 资源推荐、系统资料与收藏
6. 测评、错题本与复习
7. 学习报告与通知
8. 教师工作台
9. 知识库管理
10. 常见问题与故障排查

### 5.2 帮助首页

帮助首页的首要任务是让用户找到答案，页面结构为：

- 标题和一句说明。
- 搜索框，支持功能名、页面名、现象和关键词。
- 三个快速开始入口：第一次使用、开始一次学习、生成学习资料。
- 按用户任务排序的常用操作列表。
- 左侧分类目录；移动端收进抽屉。

页面不使用大面积折叠卡片堆叠。列表行展示标题、摘要、分类和预计阅读时间，点击进入文章详情。

### 5.3 文章详情

文章详情采用“分类目录 + 正文 + 本页目录”的宽屏结构：

- 左侧显示当前分类及相关文章。
- 中间显示文章正文。
- 右侧显示当前文章目录，仅在宽屏显示。
- 中小屏隐藏右侧目录，分类目录进入抽屉。

每篇文章必须包含：

1. 功能解决什么问题。
2. 适用角色和预计阅读时间。
3. 操作前准备。
4. 编号步骤。
5. 带编号标注的真实系统截图。
6. 操作成功后的预期结果。
7. 常见失败现象和解决方法。
8. 指向真实路由的“前往操作”。
9. 支持导览的文章显示“重新播放导览”。

## 6. 内容模型

现有帮助内容扩展为结构化 `HelpArticle`，建议字段：

```ts
type HelpArticle = {
  id: string;
  categoryId: string;
  title: string;
  summary: string;
  audience: Array<'student' | 'teacher' | 'admin'>;
  keywords: string[];
  estimatedMinutes: number;
  updatedAt: string;
  prerequisites: string[];
  sections: HelpArticleSection[];
  action?: { label: string; href: string };
  tourId?: string;
};
```

文章内容第一阶段继续由前端静态 TypeScript 数据管理，便于类型检查、路由生成和测试。文章内不写 API key、签名地址、本地绝对路径或隐私数据。

## 7. 截图素材规范

原始截图从仓库内的页面截图材料中选择，实施时复制到 `OpenMAIC/public/a3/help/` 下并改为稳定 ASCII 文件名。

- 每张图必须对应当前真实页面。
- 标注只解释真实可操作区域。
- 截图中的用户信息必须是演示账号或已脱敏数据。
- 截图使用固定宽高约束，加载状态不得导致文章跳动。
- 图片点击后可放大查看；关闭、键盘 Escape 和焦点返回必须可用。
- 截图失效时显示替代文本和“界面可能已更新”的提示，不阻断文章其余内容。

## 8. 首批新手导览

首批仅覆盖以下五个高难度流程：

| 导览 | 目标页面 | 说明 |
|---|---|---|
| 学习画像设置 | `/a3/profile-setup` | 解释上方引导、对话采集和下方手动编辑的关系 |
| 入学诊断 | `/a3/admission-diagnostic` | 解释诊断目的、作答、提交和结果回流 |
| 今日任务与学习计划 | `/a3/today`、`/a3/study-plan` | 解释今天做什么、周期计划和完成回流 |
| 个性化资源生成 | `/a3/recommendations` | 解释上下文、需求输入、资源类型、生成记录 |
| 知识库上传与解析 | `/a3/knowledge-base` | 解释上传、解析状态、检索和失败重试 |

每个导览遵守：

- 3 至 5 步。
- 有标题、简短说明、当前步数、上一步、下一步、跳过和关闭。
- 最后一步显示“完成”，不自动执行用户操作。
- 支持“不再自动提示”。
- 可从文章详情或顶部问号重新播放。
- 同一时间只允许一个导览存在。
- 返回用户不被重复打扰，除非导览版本升级。

## 9. 导览配置与持久化

导览使用结构化前端配置：

```ts
type GuidedTour = {
  id: string;
  version: number;
  routes: string[];
  audience: Array<'student' | 'teacher' | 'admin'>;
  steps: Array<{
    id: string;
    target: string;
    title: string;
    description: string;
    placement: 'top' | 'right' | 'bottom' | 'left';
  }>;
};
```

目标元素使用稳定的 `data-tour-id`，不依赖易变化的 CSS 类名或文本内容。

第一阶段不新增后端接口。完成状态存储在浏览器本地，键名包含当前用户、导览 ID 和版本：

```text
a3-tour:<user-id>:<tour-id>:<version>
```

仅存储 `completed`、`dismissed` 和时间，不存储学习内容或隐私信息。用户主动从帮助中心重播时忽略完成状态。

## 10. 触发和降级规则

自动触发必须同时满足：

- 用户已登录并具有匹配角色。
- 当前路由匹配导览配置。
- 当前版本未完成或未跳过。
- 页面主要数据已经加载。
- 当前没有对话输入、文件上传、资源生成、测评提交或其他阻断性操作。
- 第一个目标元素真实存在且可见。

降级规则：

- 某一步锚点缺失时跳过该步，不显示指向空白区域的浮层。
- 所有锚点都缺失时关闭导览，并提供进入对应帮助文章的入口。
- 路由跳转或权限变化时安全关闭当前导览。
- 异步加载后锚点短暂不存在时允许有限等待，超时后执行缺失锚点规则。
- 导览失败不能阻断页面主任务。

## 11. 交互与可访问性

- 遮罩降低背景干扰，但高亮区域保持清晰可见。
- 浮层不遮挡目标元素的核心内容和主要操作。
- 键盘可使用 Tab、Shift+Tab、Enter 和 Escape。
- 浮层使用合适的对话框语义并管理焦点。
- 关闭后焦点返回启动导览的按钮或原始目标。
- 移动端根据可用空间自动调整浮层位置；无法可靠锚定时使用底部说明面板。
- `prefers-reduced-motion` 下关闭平滑移动动画。

## 12. 组件边界

建议保持以下职责分离：

- `help-center-view`：帮助首页搜索和分类。
- `help-article-view`：文章详情渲染。
- `help-content`：分类和文章结构化数据。
- `guided-tour-provider`：单实例导览生命周期。
- `guided-tour-overlay`：遮罩、高亮和浮层展示。
- `guided-tour-config`：五个导览的配置。
- `tour-storage`：按用户和版本读写本地完成状态。

导览组件只消费目标选择器和文案，不了解画像、推荐或知识库的业务实现。业务页面只负责提供稳定 `data-tour-id`。

## 13. 测试与验证

### 帮助中心

- 搜索标题、摘要、关键词和常见错误现象。
- 分类过滤和清空搜索。
- 无结果状态提供返回全部分类的动作。
- 每篇文章路由可访问，未知文章返回正常未找到页面。
- 每个“前往操作”指向允许的真实 A3 路由。
- 截图具有 `alt`，放大预览可关闭并恢复焦点。

### 新手导览

- 首次访问按角色和路由触发。
- 完成或跳过后不再自动触发。
- 版本升级后可以重新触发。
- 从帮助文章可以主动重播。
- 缺失单个锚点时跳过，全部缺失时安全关闭。
- 导览期间路由变化、窗口缩放和移动端布局不产生遮挡或残留遮罩。

### 基础验证

- `npx.cmd tsc --noEmit`
- `pnpm.cmd lint`
- 相关 Vitest 组件和内容契约测试。
- Playwright 覆盖帮助首页、文章详情、桌面导览和移动端导览。

## 14. 实施阶段

### 阶段一：帮助中心骨架

- 扩展分类和文章内容模型。
- 升级 `/a3/help` 搜索、分类和快速开始。
- 增加稳定导航入口。

### 阶段二：文章详情与截图

- 增加 `/a3/help/[articleId]`。
- 录入首批完整文章。
- 接入真实截图、编号标注、放大预览、故障处理和真实路由行动。

### 阶段三：选择性新手导览

- 建立通用导览组件、配置和本地持久化。
- 为五个目标流程增加稳定锚点。
- 从顶部问号和帮助文章提供重播入口。

## 15. 验收结果

完成后，用户可以从独立帮助中心按任务找到答案，进入带真实截图的文章完成操作；首次进入五个复杂流程时，可以通过短导览理解当前页面。公开首页、帮助中心和业务页面导览保持独立，且不修改后端或 Agent 接口。
